# APPCOREJS SERVER

Minimal server rules and facts.

## Mandatory Layer Rule

Server classes in project code must extend and use app server classes.
Project server code must not bypass app to use core server classes directly when app counterparts exist.

## Server Architecture Facts

- Root `server.js` instantiates the project server class generated by CLI.
- App `Server` extends `CoreServer`.
- Server components are attached with `registerServerComponent(...)`.

## Synchronization Facts

- CLI creates root `server.js` only if missing.
- CLI creates project server class only if missing.
- Existing project server files are preserved.

## Recommendation

Put reusable server behavior in app server components and business endpoints in project components.
